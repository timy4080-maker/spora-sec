# Spora SEC-01

Рабочий прототип с **libsignal v0.108.0**, закреплённым на `8be00c282001caa3585d18de0f044c6d500348ab`. Синтетический provider заменён настоящим шифрованием в отдельном клиенте и новом формате профиля. Существующие тестовые профили не мигрируют.

**M2 не закрыт.** По решению владельца требуется security review внешним специалистом. До него стенд предназначен для искусственных сообщений. TLS-стенд воспроизведён локально; публичное интернет-развёртывание в этой работе не заявляется.

Реализованы адресные подписанные приглашения с обязательной сверкой отпечатка, независимые сессии устройств, PQXDH/Triple Ratchet через libsignal, приватные обёртки маршрутов, приём до consume, durable receipt intents, атомарное сохранение полного состояния SQLite, перезапуск и повтор запросов. Один профиль обслуживает одно устройство.
